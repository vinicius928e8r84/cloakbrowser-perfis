# Fatos do CloakBrowser para outras partes do mapa

Achados de passagem na pesquisa [Algum repositório do CloakHQ ou do browser-use ajuda o aquecimento?](https://github.com/vinicius928e8r84/cloakbrowser-perfis/issues/21) (ver [repos-aquecimento.md](repos-aquecimento.md)), lidos no README e no código do CloakBrowser 0.7.3 em 2026-11-26. Não respondem àquele ticket, mas tocam a névoa do mapa.

- **Mesmas versões nos dois Macs.** `CLOAKBROWSER_AUTO_UPDATE=false` "keep the cached build and skip update checks" ([README L650](https://github.com/CloakHQ/CloakBrowser/blob/09b1bf62a2fae23128772df4974a49ccac8abc5d/README.md#L650)); no código, com a atualização congelada e um build no cache, ele usa o do cache sem perguntar ao servidor, e sem build no cache ainda baixa um ([`download.py` L483–L490](https://github.com/CloakHQ/CloakBrowser/blob/09b1bf62a2fae23128772df4974a49ccac8abc5d/cloakbrowser/download.py#L483-L490)). A mesma variável desliga o aviso de versão nova da biblioteca ([`download.py` L1064–L1071](https://github.com/CloakHQ/CloakBrowser/blob/09b1bf62a2fae23128772df4974a49ccac8abc5d/cloakbrowser/download.py#L1064-L1071)). Fixar uma versão exata (`CLOAKBROWSER_VERSION`) é "Paid Pro key only. A free key cannot pin: it ignores the pin and always gets the latest build", e "unpinned launches always use the latest available version" ([README L1209–L1225](https://github.com/CloakHQ/CloakBrowser/blob/09b1bf62a2fae23128772df4974a49ccac8abc5d/README.md#L1209-L1225)). O Manager não define nenhuma das duas variáveis hoje.
- **Licença em dois Macs.** A chave grátis dá "one concurrent session"; o Pro sobe para "5, 20, 200, 2,000, or more concurrent sessions" ([README L191–L192](https://github.com/CloakHQ/CloakBrowser/blob/09b1bf62a2fae23128772df4974a49ccac8abc5d/README.md#L191-L192)).
